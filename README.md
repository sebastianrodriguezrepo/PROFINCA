Pagina web [ Profinca Jireth ] 

Primer proyecto que realice para una microempresa de Barrancabermeja que distribuye carnes frias al por mayor, la pagina web fue realizada de visual estudio code,
estructurado en index, los estilos y el script, fue realizado con el lenguaje javascript.

La pagina web permite: 

-Llegar a la direccion del lugar real por medio de waze o google maps

-Ver todos los productos disponibles con las imagenes reales de lo que son

-Añadir los productos al carro, y acumular la suma de precio a medida que se añaden.

-Una vista por si el cliente quiere ver la historia de la empresa, provedores y su metas futuras.

-Al terminar el carro, opcion de decir si es para domicilio, o ir hasta el sitio real.

-Te pide el nombre

-Opción de pagar por datafono, efectivo, nequi etc.

-Al darle terminar mi pedido, sale en un icono de whatsApp para que lo rediriga al numero de la empresa y mandar el pedido y la tienda haga el resto. 

Este proyecto lo hice para familializarme con la creacion de paginas webs, poco a poco ir avazando, tambien lo hice para poder ayudar a esta microempresa,
ya que esta pagina web puede brindarle nuevas ventas.
